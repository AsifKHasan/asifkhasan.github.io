# তারাশঙ্কর বন্দ্যোপাধ্যায়

##  কবি
----------------------------------------------------------------------------------
<pre>
  লোকে কয় আমি কৃষ্ণ-কলঙ্কিনী
  সখী সেই গরবে আমি গরবিনী গো,
  আমি গরবিনী।
</pre>

----------------------------------------------------------------------------------
<pre>
  ও তার নামের গুনে গহন বনে, মৃত তরু মুঞ্জরে,
  নামের তরী বাঁধা ঘাটে ডাকলে সে যে পার করে।
</pre>
