# জলধর সেন

## হিমালয়
----------------------------------------------------------------------------------
<pre>
  গোলমালে মাল মিশে আছে;
  ওরে, গোল ছেড়ে মাল লওরে বেছে।
</pre>

<pre>
  ইয়ে রসনা বশ কর, ধর গরিবি বেশ,
  শীতল বুলি লেকে চল, সবই তুমহারা দেশ।
</pre>
